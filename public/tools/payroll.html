공무직·기간제 직원 보수 지급내역 작성툴 최종양식·조견표 반영형

업로드한 엑셀의 성명을 기준으로 보수 지급내역 한 줄을 생성하고, 전월 자료를 성명 기준으로 복사합니다. 간이세액표를 앱 내부에 임베드하여 부양대상 가족 수 기준으로 근로소득세·지방소득세를 자동 산출하고, 사회보험 고지서를 개별 업로드해 보험료를 반영하고, 초과근무 계산표와 예산과목별 기관부담금 산정파일을 생성합니다.

1. 기본 설정 및 자료 업로드

저장 상태 확인 중
G열 연금보험료의 1/2을 우선 반영하고, 실패 시 노란색 고지분 셀을 보조 인식합니다.
N열 건강보험·AA열 장기요양 고지보험료를 우선 반영하고, 실패 시 노란색 셀을 보조 인식합니다.
J열 근로자실업급여보험료를 우선 반영하고, 실패 시 노란색 셀을 보조 인식합니다.
N열 보험료합계를 회담본부 부담 산재보험으로 반영하고, 실패 시 노란색 셀을 보조 인식합니다.
통합 사회보험 산출내역 파일을 한 번에 반영하려면 클릭
국민·건강·고용·산재·산출세부내역 탭을 한 번에 읽습니다.
세액 검증 대기
업로드 파일에 보수내역 시트가 있으면 A~V열 기준헤더 양식을 직접 읽습니다. 일반 명단 파일이면 성명·부서·직종·비고 칼럼을 자동 추정합니다. 사회보험 고지서는 국민연금·건강보험·고용보험·산재보험 파일을 각각 업로드하여 성명 기준으로 반영합니다. 원칙은 열 기준이며, 해당 열에서 유효값을 찾지 못하면 같은 탭의 노란색 고지분 셀을 보조 기준으로 탐색합니다. 통합 사회보험 산출내역 파일도 접어서 제공하는 보조 업로드 영역에서 일괄 반영할 수 있습니다. 3번 영역에서 보험 고지서 업로드 원자료 기준으로 사회보험 내역 XLSX를 별도로 생성할 수 있습니다. 보수지급 내역과 미매칭된 인원도 파일에 포함됩니다. 소득세는 앱에 내장된 간이세액표와 선택한 공제대상 가족 수로 자동 산출하고, 지방소득세는 근로소득세의 10%를 10원 단위 절사하여 반영합니다. 예시 양식 다운로드 버튼으로 명단 입력용·보험 고지서 업로드용 샘플 XLSX를 받을 수 있습니다. 성명순 정렬 후에도 원래대로 버튼으로 업로드 당시 순서로 복원할 수 있습니다.

2. 보수 지급내역 입력

금액은 원 단위 입력. 급여 항목 변경 시 자동계산 모드에서는 근로소득세·지방소득세까지 재산출됩니다.

2-1. 초과근무 계산기

합산시간 = 연장시간×1.5 + 야간근무시간×0.5 + 휴일근무시간×1.5 + 휴일연장시간×2.0입니다. 통상시급은 근로자별 칸에 직접 입력합니다. 시간외수당 반영 시 합산시간 × 통상시급을 10원 단위 절사해 2번 보수내역의 시간외수당 칸에 반영합니다.
엑셀 다운로드 시 이 계산표는 초과근무계산 탭으로 보수내역과 함께 저장됩니다.

3. 사회보험 내역 파일 생성

국민연금·건강보험·고용보험·산재보험 업로드 원자료를 기준으로 보수지급 내역과 독립적으로 산출(총)세부내역 양식 XLSX를 생성합니다.
생성 기준: 국민연금은 근로자부담과 사업주부담을 동일 금액으로 반영, 건강보험·장기요양은 근로자/사업주 동일 금액으로 반영, 고용보험은 고지서의 근로자실업급여보험료와 사업주 실업급여·고용안정 금액을 반영합니다. 산재보험은 업로드한 산재 고지서의 N열 보험료합계를 사업주부담으로 반영합니다. 보수내역 일치자만 보기를 선택하면 5개 부서 전체 고지서 중 현재 2번 보수내역 성명과 일치하는 인원만 미리보기와 다운로드에 반영됩니다.
사회보험 내역 미리보기 대기전체 보기
현재 보기 기준이 사회보험 내역 다운로드에도 그대로 적용됩니다. 전체 고지서 원자료를 보존하려면 전체 보기, 해당 부서 명단만 산출하려면 보수내역 일치자만 보기를 사용하십시오.

4. 기관부담금 산정파일 생성

3번 사회보험 내역의 사업주부담금을 예산과목/비고 기준으로 집계합니다.
생성 기준: 3번 미리보기의 마지막 열 예산과목/비고를 예산과목으로 사용하고, 국민연금·건강보험·고용보험·산재보험의 사업주부담금만 합산합니다. 건강보험에는 장기요양보험 사업주부담분을 포함합니다. 3번에서 보수내역 일치자만 보기를 선택하면 4번도 해당 부서 일치자만 집계합니다.
