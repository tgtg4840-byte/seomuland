# 나의 작은별 이야기_어린왕자 업무일지

어린왕자 테마의 업무일지 웹 애플리케이션. HTML/CSS/JavaScript 기반 클라이언트 앱입니다.

## 제출 파일 구성
- `index.html` : 출품용 분리형 HTML 진입점
- `style.css` : 전체 스타일 및 스큐어모피즘 디자인
- `app.js` : 업무/메모/달력/칸반/필드/로컬 저장 기능
- `mobile.js` : 모바일 북마크 내비게이션
- `원본_통합.html` : 배포와 동일한 단일 HTML 원본(CSS/JS 내장)

## 실행 방법
`index.html`을 브라우저에서 열면 됩니다. 외부 라이브러리 설치나 빌드 과정은 필요하지 않습니다. 일부 글꼴은 Google Fonts에서 온라인으로 로드되며, 오프라인에서는 기본 글꼴로 대체됩니다.

## 저장 방식
업무 데이터는 각 브라우저의 `localStorage`에 저장됩니다. 데이터는 소스 ZIP에 포함되지 않으므로 기존 PC의 기록은 앱에서 백업해 별도로 보관하세요.
